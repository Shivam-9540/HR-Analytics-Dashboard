# HR Analytics Dashboard 📊

## Overview

This project focuses on analyzing employee data to understand workforce trends, employee attrition, job satisfaction, salary distribution, and other HR-related metrics.

The goal is to transform raw HR data into meaningful insights using data cleaning, analysis, and interactive visualizations in Power BI. The dashboard helps HR teams identify workforce patterns and make data-driven decisions.

## Dataset

- **Dataset Name:** HR_Analytics.csv
- **Total Records:** 1,480
- **Total Columns:** 38
- **Data Type:** Human Resources / Employee Analytics

### Key Features

The dataset contains information about:

- **Employee Demographics:** Age, Gender, Marital Status, Education
- **Employment Details:** Department, Job Role, Job Level, Business Travel
- **Salary Information:** Monthly Income, Salary Slab, Salary Hike
- **Employee Satisfaction:** Job Satisfaction, Work-Life Balance, Environment Satisfaction
- **Attrition:** Employee attrition status
- **Experience:** Total Working Years, Years at Company, Years in Current Role
- **Performance:** Performance Rating and Training

## How to Run

1. Clone or download this repository.
2. Locate `HR_Analytics.csv`.
3. Open `HR_Analytics.pbix` using Microsoft Power BI Desktop.
4. If prompted, update the data source path to the location of the CSV file.
5. Refresh the dataset if required.
6. Explore the dashboard using its visualizations and filters.

**Prerequisites:**
- Microsoft Power BI Desktop
- The provided CSV dataset
